# PM ELab2b 2026-2 – Xulambs Fit (Modelo B)

Esqueleto da Atividade Pontuada em Laboratório 2 – Modelo B (3 pontos).

## O que fazer

1. Faça um **fork** deste repositório para o seu usuário.
2. Clone o fork no computador do laboratório e abra na IDE.
3. Crie a branch `Aula2010` a partir da `main`.
4. Habilite os testes com **JUnit Jupiter**.
5. Complete os `//TODO` e escreva **2 testes** em `ProfissionalTest` (um deles deve cobrir `registrarPagamento`).
6. Commit `Final da atividade` e publique a branch.

Enunciado completo e diagrama UML estão no Canvas / material da disciplina.
